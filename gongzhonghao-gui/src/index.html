📖 使用说明

一、配置密钥

首次使用需要配置三个密钥信息：

Auth Key（第三方API密钥）

用于搜索公众号、获取文章列表、下载文章内容。

获取地址：https://down.mptext.top/dashboard/api

步骤：微信扫码登录 → 左侧目录点击「API」→ 查询 API 密钥

⚠️ 注意：密钥有效期为 4 天，过期后需重新登录获取

AppID（微信公众平台）

微信公众平台的唯一标识。

获取地址：https://developers.weixin.qq.com/platform

步骤：微信扫码登录 → 选择自己的公众号 → 「基础信息」→「APPID

AppSecret（微信公众平台）

与 AppID 配套使用，用于获取 AccessToken。

获取方式：同 AppID，在同一页面获取

⚠️ 配置 API IP 白名单

重要：需要在微信公众平台配置 IP 白名单，否则 API 调用会失败！

步骤：开发设置 → IP 白名单 → 添加本机 IP

查看本机 IP：https://ip.cn

提示：配置完成后点击「保存」按钮，配置会自动保存到本地。

二、使用流程

1
搜索公众号
在顶部的搜索框输入公众号名称，点击「搜索」按钮
2
选择公众号
点击左侧列表中的公众号，右侧会显示该公众号的文章列表
3
筛选文章
在筛选框输入关键词，点击「筛选」按钮过滤文章
4
发布文章
勾选要发布的文章，点击「发布选中文章」按钮
5
完成
发布成功后，文章会出现在微信公众平台的「草稿箱」中

三、常见问题

Q: 文章封面图不显示怎么办？
A: 确保网络可以正常访问微信图片域名。如持续有问题，尝试重启应用。
Q: 发布失败怎么解决？
A: 检查 AppID 和 AppSecret 是否正确，确保微信公众平台账号有素材库权限。详细错误信息可在底部日志查看。
Q: 请求超时怎么办？
A: 系统会自动重试最多3次。如网络不稳定，建议稍后再试。
