# 公众号文章采集工具

一个用于采集微信公众号文章并发布到草稿箱的桌面工具。

## 功能特点

- 搜索公众号（显示头像、名称、简介）
- 查看公众号文章列表（显示封面图、标题、日期）
- 关键词筛选文章
- 批量发布文章到微信草稿箱
- 支持配置保存

## 环境要求

- Node.js 16+
- npm
- Windows/macOS/Linux

## 安装

```bash
cd gongzhonghao-gui
npm install
```

## 运行

```bash
npm run start
```

## 使用步骤

### 1. 配置密钥

首次使用需要填写以下信息：

| 字段 | 说明 |
|------|------|
| Auth Key | 第三方API密钥（用于搜索公众号、获取文章、下载内容） |
| AppID | 微信公众平台 AppID |
| AppSecret | 微信公众平台 AppSecret |

配置后点击「保存」。

### 2. 搜索公众号

在任务页面输入公众号名称，点击「搜索」。

搜索结果会显示在左侧列表，包括：
- 公众号头像
- 公众号名称
- 简介

### 3. 选择公众号

点击左侧列表中的公众号，右侧会加载该公众号的文章列表。

### 4. 筛选文章

在文章列表上方的筛选框输入关键词，点击「筛选」按钮进行过滤。点击「重置」可清除筛选条件。

### 5. 发布文章

1. 勾选要发布的文章（支持多选）
2. 点击「发布选中文章」按钮
3. 等待发布完成，底部日志会显示结果

发布成功后，文章会出现在微信公众平台的「草稿箱」中。

## 常见问题

### 文章封面图不显示
确保网络可以正常访问微信图片域名。如有问题，重启应用。

### 发布失败
- 检查 AppID 和 AppSecret 是否正确
- 确保微信公众平台有发布权限
- 查看底部日志获取详细错误信息

### 超时
网络不佳时请求可能较慢，系统会自动重试（最多3次）。
